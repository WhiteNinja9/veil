# Internationalisation

Veil ships in **English**, **Arabic** (right-to-left) and **French**. Users choose a language in
Settings → General, or leave it on _Automatic_ to follow the browser's UI language, falling back
to English.

## Two layers

| Layer              | Used for                                                                                    | Files                                       |
| ------------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Browser `_locales` | Strings the browser shows: extension name, description, action title, shortcut descriptions | `static/_locales/{en,ar,fr}/messages.json`  |
| Runtime catalogues | All of Veil's own UI: popup, settings, onboarding, interstitial, in-page chip and menus     | `src/i18n/locales/{app,page}.{en,ar,fr}.ts` |

The runtime layer exists because `chrome.i18n` can't switch language without restarting the browser.
Veil switches instantly.

- **App catalogue:** about 410 keys, used by extension pages.
- **Page catalogue:** 22 keys, used by the content script. It is kept tiny so every frame loads
  little.

## API

```ts
const t = appTranslator(settings.language); // 'auto' | 'en' | 'ar' | 'fr'
t.t('sites.expires', { time: t.relativeTime(rule.expiresAt) });
t.t('popup.engine.unverified', { count: 3 }); // plural
t.number(1234.5); // locale digits and separators
t.percent(0.42);
t.list(['a', 'b', 'c']); // "a, b, and c" / "a et b et c" / Arabic conjunctions
t.dir; // 'ltr' | 'rtl'
```

- **Placeholders** are `{name}`. Numbers passed as parameters are formatted for the locale.
- **Plurals** are objects keyed by `Intl.PluralRules` categories, with `#` standing for the
  formatted count:

  ```ts
  'common.minutes': { one: '# minute', other: '# minutes' },                  // en
  'common.minutes': { zero: '# دقيقة', one: 'دقيقة واحدة', two: 'دقيقتان',
                      few: '# دقائق', many: '# دقيقة', other: '# دقيقة' },    // ar: six forms
  ```

- **Completeness is enforced by the compiler:** each non-English catalogue is typed against the
  English keys, so a missing or misspelt key fails `npm run typecheck`. `tests/unit/i18n.test.ts`
  also checks that placeholders match across languages and that plural objects carry the forms
  each language needs.

## Right-to-left

- `<html dir>` and `lang` are set from the active translator (`src/ui/app-context.tsx`).
- **Layout** uses logical CSS properties throughout (`margin-inline-start`, `inset-inline-end`,
  `padding-inline`), so it mirrors without per-language overrides.
- **Directional icons** (chevrons, back arrow, external link) carry `.icon-directional` and flip in
  RTL. Other icons stay put.
- **Controls:** the segmented control's arrow keys follow visual order in RTL, and sliders and
  switches mirror.
- **Mixed direction:** host names are always laid out left-to-right. Inside a translated sentence
  (the interstitial) they are wrapped in Unicode first-strong isolates (U+2068…U+2069). On their
  own (popup, site list) they get `direction: ltr`. Either way `example.com` stays readable inside
  Arabic text.
- **Fonts:** Arabic uses the platform's Arabic UI font stack (`--font-arabic`); Latin text uses
  Inter.
- The in-page chip and reveal controls follow the **user's** language direction, not the page's.

## French

- Typography: a narrow no-break space (U+202F) before `: ; ? !` and inside « guillemets », as French
  convention requires.
- Numbers use a narrow no-break space as the thousands separator via `Intl.NumberFormat`.

## Adding a language

1. Add the code to `Locale` and `LOCALES` in `src/i18n/core.ts` (and to `RTL_LOCALES` if needed).
2. Copy `app.en.ts` and `page.en.ts` to the new code and translate. The compiler lists anything
   missing.
3. Add `static/_locales/<code>/messages.json`.
4. Add the language to `LANGUAGE_NAMES` (in its own script) and to the settings schema's `LANGUAGES`.
5. Run `npm run check`, then the E2E accessibility test, which renders every page, and review
   screenshots (`node scripts/screenshots.mjs`) for truncation and wrapping.

Translate meaning, not words. The copy is calm and plain on purpose, with no guilt, urgency or
alarm; keep that tone in every language.
